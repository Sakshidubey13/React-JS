# 🚀 Next.js Navigation App

A simple multi-page navigation project built using Next.js App Router.

This project demonstrates:

- 🔗 Navigation using `Link`
- 🚀 Programmatic navigation using `useRouter`
- 📂 Multiple page routing
- ⚡ Next.js App Router
- 🎨 Tailwind CSS styling

---

# 📸 Features

✅ Home Page  
✅ About Page  
✅ Profile Page  
✅ Contact Page  
✅ Navigation Bar  
✅ Button Navigation  
✅ Responsive Layout  

---

# 🛠️ Technologies Used

- Next.js
- React.js
- Tailwind CSS

# 🧠 Concepts Learned

## 🔗 Link Navigation

Used for moving between pages.

```jsx
<Link href="/profile">Profile</Link>
```

---

## 🚀 useRouter Navigation

Used for button click navigation.

```jsx
router.push("/about")
```

# ⚙️ Installation

## 1️⃣ Create Next.js App

```bash
npx create-next-app@latest my-app --src-dir --tailwind --yes
```

---

## 2️⃣ Go to Project Folder

```bash
cd my-app
```

---

## 3️⃣ Run Development Server

```bash
npm run dev
```
