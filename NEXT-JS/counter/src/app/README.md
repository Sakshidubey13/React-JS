# 🚀 Counter App using Next.js + Tailwind CSS

## 🎥 Project Demo

https://github.com/user-attachments/assets/ef9dd19b-f3d2-487b-ac75-0b3d153a64df

A stylish Counter App with animated buttons and premium UI built using Next.js and Tailwind CSS.
## ✨ Features

- ➕ Increment Counter
- ➖ Decrement Counter
- ✖️ Multiply Counter by 2
- ➗ Divide Counter by 2
- 🎨 Premium Gradient Buttons
- ⚡ Smooth Hover Animations
- 📱 Responsive UI

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone <your-repository-link>
```

## 2️⃣ Open Project Folder

```bash
cd counter-app
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Run Development Server

```bash
npm run dev
```

Now open:

```bash
http://localhost:3000
```
