# 🚀 Counter App using Next.js + Tailwind CSS


A simple and stylish Counter Application built with Next.js and Tailwind CSS.

## ✨ Features

- ➕ Increment Counter
- ➖ Decrement Counter
- ✖️ Multiply Counter by 2
- ➗ Divide Counter by 2
- 🎨 Premium Gradient Buttons
- ⚡ Smooth Hover Animations
- 📱 Responsive UI

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone <your-repository-link>
```

## 2️⃣ Open Project Folder

```bash
cd counter-app
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Run Development Server

```bash
npm run dev
```

Now open:

```bash
http://localhost:3000
```
